# ENTSO-E Transparency Platform Data Reference

A practical reference for retrieving and organizing electricity-market and
power-system data from the ENTSO-E Transparency Platform using
[`entsoe-py`](https://github.com/EnergieID/entsoe-py).

The available API methods are grouped into six functional categories:

1. Market
2. Load
3. Generation
4. Transmission
5. Congestion Management
6. Balancing
